# 🎋 Kakeibo (家計簿) · Японські конверти та калькулятор боргів

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/tolik085/kakeibo-envelopes)

Сучасний інтерактивний веб-додаток для планування особистого бюджету за японською методикою 4-х конвертів (Kakeibo) та математично точного розрахунку дострокового погашення боргів і кредитів за стратегіями **«Лавина» (Avalanche)** та **«Снігова куля» (Snowball)**.

---

## 🌟 Основні можливості

1. **Базові принципи Kakeibo**:
   - Чіткий поділ на необов'язкові витрати (на чому заощаджувати) та недоторканні базові потреби.
   - 4 ключові запитання усвідомленого споживання.

2. **Інтерактивний психологічний тест**:
   - Допомагає обрати між швидкою мотивацією («Снігова куля» ⛄) та максимальною грошовою економією («Лавина» 🏔️).
   - Встановлення обраної стратегії в калькулятор в 1 клік.

3. **Професійний калькулятор боргів**:
   - Додавання будь-якої кількості кредитів, розстрочок або карток із зазначенням залишку, ставки % річних та мін. платежу.
   - Додатковий щомісячний прискорювач виплат.
   - Порівняння стратегій «Лавина» та «Снігова куля» пліч-о-пліч з розрахунком заощаджених грошей та місяців!
   - Інтерактивний графік динаміки зниження боргу за місяцями (Chart.js).

4. **Розподіл бюджету за конвертами**:
   - Облік кількох джерел доходів (зарплата, аванс, фриланс).
   - Відокремлення фонду цілей та боргів.
   - Зручні повзунки з процентним розподілом та швидкими пресетами (Збалансований, Ощадливий, Активний).
   - Автоматичний розрахунок місячного, тижневого та денного ліміту витрат для кожного конверта:
     - 🏠 **Необхідне** (基本)
     - 🛍 **Бажання** (娯楽)
     - 🌱 **Розвиток** (成長)
     - 🛡️ **Непередбачуване** (備え)

5. **Гнучкість та приватність**:
   - 💱 **Мультивалютність**: швидке перемикання між ₼ AZN, ₴ UAH, $ USD, € EUR, zł PLN.
   - 💾 **Автозбереження**: всі дані автоматично зберігаються у вашому браузері (`localStorage`) — нічого не загубиться при перезавантаженні.
   - 🔒 **100% приватність**: розрахунки відбуваються тільки на вашому пристрої без відправки на сервери.
   - 🖨️ **Друк та PDF**: вбудована оптимізована версія для друку або збереження у файл PDF.

## 🚀 Як відкрити локально

### Варіант 1: Відкрити прямо в браузері (без встановлення)
Просто двічі клацніть на файл `index.html` або перетягніть його у будь-який браузер.

### Варіант 2: Запуск локального веб-сервера
У папці проекту виконайте:
```bash
npm start
```
Відкрийте у браузері: [http://localhost:3000](http://localhost:3000)

---

## ⚡ Розгортання на Render (Автоматичний безкоштовний деплой)

1. Перейдіть у панель [Render Dashboard](https://dashboard.render.com).
2. Натисніть **New +** -> **Static Site**.
3. Оберіть репозиторій `tolik085/kakeibo-envelopes`.
4. Залиште поля за замовчуванням (Build Command: порожньо, Publish Directory: `.`).
5. Натисніть **Create Static Site**.

Render створить безкоштовне посилання на сайт із безкоштовним SSL-сертифікатом. Кожен новий `git push` у репозиторій автоматично оновлюватиме сайт на Render!
